# MPD Direct Sale (Preview)

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้อง build) ข้อมูลใน `data.js` เป็นตัวอย่างสำหรับ Preview
และสิ่งที่บันทึกจะเก็บใน localStorage ของเบราว์เซอร์เท่านั้น
