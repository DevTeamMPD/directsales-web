# JST Helper (ตัวช่วยเปิดแชตใน JST บนเครื่องเซลล์)

ให้เว็บ **MPD Direct Sale** เปิดแชตของลูกค้าใน JST ให้อัตโนมัติ
- กด **ไอคอนช่องทาง** (LINE / Shopee / Facebook / …) ในหน้าลูกค้า
- หรือกด **"จอง"** ลูกค้า (ขุด) เว็บจะส่งชื่อแชตของลูกค้ามาที่ตัวช่วยนี้ แล้วตัวช่วยเปิด JST ให้

ตัวช่วยรันบนเครื่องของเซลล์เอง (เพราะ JST อยู่บนเครื่องเซลล์) ถ้าไม่ได้รัน เว็บจะ **คัดลอกชื่อแชต** ให้ไปวางค้นหาใน JST แทน ไม่พัง

## ติดตั้ง (Windows)
1. ติดตั้ง [Node.js](https://nodejs.org) (เวอร์ชัน 18 ขึ้นไป)
2. คัดลอกโฟลเดอร์ `tools/jst-helper` ไปไว้ในเครื่อง เช่น `C:\jst-helper`
3. คัดลอก `config.example.json` เป็น `config.json` แล้วตั้งค่า (ดูด้านล่าง)
4. ดับเบิลคลิก `start-windows.bat` (ปล่อยหน้าต่างไว้ขณะทำงาน) ควรเห็น `JST Helper … พร้อมใช้งาน`

macOS / Linux: `node jst-helper.js`

## ตั้งค่า `config.json`
| คีย์ | ความหมาย |
|---|---|
| `allowedOrigins` | เว็บที่อนุญาตให้สั่งตัวช่วย (ค่าเริ่มต้น `https://directsales-web.vercel.app`) ใส่โดเมนบริษัทเพิ่มได้ |
| `mode` | `"url"` เปิดลิงก์ JST ด้วยเบราว์เซอร์ / `"command"` รันโปรแกรมของคุณ (AutoHotkey, Python ฯลฯ) |
| `urlTemplate` | (โหมด url) ลิงก์แชตของ JST ใช้ตัวแปร `{chat} {phone} {name} {shop} {platform} {brand} {ms_id} {rep}` (เข้ารหัส URL ให้เอง) |
| `command` | (โหมด command) รายการอาร์กิวเมนต์ เช่น `["python","open_jst.py","{chat}","{shop}"]` ค่าจากเว็บส่งเป็นอาร์กิวเมนต์ตรงๆ **ไม่ผ่านเชลล์** |

### ที่ต้องรู้จาก JST ก่อนใช้งานจริง
ผมไม่ทราบรูปแบบลิงก์/การเปิดแชตของ JST ที่ทีมใช้ จึงยังไม่ได้ตั้งค่าให้ เลือกอย่างใดอย่างหนึ่ง:
1. **มีลิงก์ตรงไปยังแชต** (เช่น มี `ms_id` ในลิงก์) → ตั้ง `urlTemplate` โหมด `url`
2. **JST เป็นโปรแกรมบนเครื่อง** → ใช้โหมด `command` กับสคริปต์ที่โฟกัสหน้าต่าง JST แล้วค้นหาชื่อแชต ดูตัวอย่าง `examples/focus-jst.ahk`

เว็บส่งข้อมูลนี้ให้ตัวช่วย: `phone, name, brand, platform (line/shopee/…), shop (เช่น LOA_bebeplay), chat (ชื่อแชต), ms_id (ถ้ารู้), rep (ชื่อเซลล์)`

## ความปลอดภัย
- ฟังเฉพาะ `127.0.0.1` (เครื่องตัวเอง) เครื่องอื่นในเครือข่ายเรียกไม่ได้
- ตอบเฉพาะเว็บใน `allowedOrigins` และจำกัดขนาดคำขอ
- ไม่ส่งค่าจากเว็บผ่านเชลล์ จึงฉีดคำสั่งไม่ได้ (มีชุดทดสอบ)
- ไม่เก็บ/ส่งข้อมูลออกนอกเครื่อง บันทึกบนหน้าจอเฉพาะเวลา ช่องทาง และร้าน
