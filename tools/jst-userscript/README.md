# เปิดแชต JST อัตโนมัติ (สคริปต์ Tampermonkey)

กดไอคอนแชต (LINE / Shopee / Facebook …) หรือกด "จอง" ในเว็บ **MPD Direct Sale** แล้ว:
1. เว็บเปิดหน้าแชต JST (`https://asia-web.jsterp.com/iim/index`) ในแท็บ JST เดิม (ไม่เปิดแท็บใหม่ทุกครั้ง) และคัดลอกชื่อแชตลงคลิปบอร์ด
2. สคริปต์นี้ในหน้า JST ตั้งช่องค้นหาเป็น **Buyer Name** ใส่ชื่อลูกค้า กดค้นหา แล้วเปิดห้องแชตที่ตรงให้เอง

ไม่ได้ติดตั้งสคริปต์ = ยังใช้ได้ เว็บเปิดหน้า JST + คัดลอกชื่อไว้ ให้กด Ctrl+V ในช่องค้นหาของ JST เอง

## ติดตั้ง (ครั้งเดียวต่อเครื่อง · Chrome บนคอม)
1. ติดตั้งส่วนขยาย **Tampermonkey** จาก Chrome Web Store
2. Chrome → จัดการส่วนขยาย (`chrome://extensions`) → Tampermonkey → **รายละเอียด** → เปิด **Allow User Scripts** (Chrome รุ่นใหม่ต้องเปิดข้อนี้ ไม่งั้นสคริปต์ไม่ทำงาน)
3. คลิกไอคอน Tampermonkey → **Create a new script** → ลบของเดิมทั้งหมด → วางเนื้อหาไฟล์ `dsales-jst.user.js` → File → Save (Ctrl+S)
4. ล็อกอิน JST ใน Chrome เครื่องนั้นไว้ (หน้า `asia-web.jsterp.com`)
5. ทดสอบ: ในเว็บ Direct Sale เปิดลูกค้าที่มีห้องแชตใน JST แล้วกดไอคอนแชต → แท็บ JST เปิดและเข้าห้องของลูกค้าเอง

## ทำงานอย่างไร
- เว็บส่งข้อมูลผ่าน hash ของลิงก์: `#dsales-chat=<ชื่อแชต>&dsales-ms=<ms_id ถ้ารู้>&dsales-t=<เวลา>` (hash ไม่ถูกส่งไปเซิร์ฟเวอร์ JST)
- สคริปต์ใช้ช่องค้นหาของหน้า JST เอง (พิมพ์ลงช่องแล้วกด Enter ผ่าน DOM) ไม่เรียก API ของ JST ตรง ไม่ส่งข้อมูลออกนอกหน้า · ใช้แค่ DOM เพราะ Tampermonkey บน Chrome รุ่นใหม่รันสคริปต์ในโลกแยก มองไม่เห็นตัวแปร JS ของหน้า (เวอร์ชัน 1.0.0 พึ่ง `__vue__` จึงเปิดแท็บได้แต่ไม่เปิดห้อง)
- ระหว่างทำงานมีแถบดำด้านบน "Direct Sale: กำลังเปิดแชต …" — ไม่เห็นแถบนี้เลย = สคริปต์ไม่ได้รัน (เช็ก Allow User Scripts / สคริปต์เปิดอยู่ใน Tampermonkey)
- เลือกห้อง: `ms_id` ตรง → ชื่อตรงทุกตัวอักษร (มีห้องเดียว) → ผลค้นหามีห้องเดียว · ถ้ามีหลายห้องชื่อซ้ำหรือไม่พบ ขึ้นแถบแจ้งด้านบนให้เลือกเอง
- ค้นหาแล้วหน้า JST จะเปิดห้องแรกให้เองอยู่แล้ว (พฤติกรรมของ JST) และการเปิดห้องทำให้ JST บันทึกบัญชีที่ล็อกอินเป็นผู้ดูแลห้องนั้น เหมือนแอดมินกดเปิดห้องเอง
- ช่องค้นหาของ JST รับได้ 50 ตัวอักษร ชื่อที่ยาวกว่าจะถูกตัด

## ข้อจำกัด
- ใช้ได้กับ Chrome/Edge บนคอมที่ติดตั้ง Tampermonkey เท่านั้น มือถือยังต้องวางชื่อค้นหาเอง
- ลูกค้าที่ระบบยังไม่รู้ชื่อแชต (ช่อง "ชื่อแชต" เป็น —) เว็บส่งชื่อจากออเดอร์ไปค้น ถ้าชื่อแชตใน JST ไม่ตรงจะค้นไม่เจอ
- อิงโครงสร้างหน้า JST (`.panel_contacts-filter`, `div.j-input > input`, `#session li[data-ms-id]`) ถ้า JST อัปเดตหน้าแล้วสคริปต์ไม่ทำงาน เว็บยังคัดลอกชื่อให้เหมือนเดิม — แจ้งทีม dev ให้ปรับสคริปต์
