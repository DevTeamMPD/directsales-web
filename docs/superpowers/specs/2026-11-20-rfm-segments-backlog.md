# RFM segment แบบระบบเก่า — งานค้าง (ทำหลังจบงาน worker ทักแชต)

> บันทึก 2026-11-20 ตามที่ผู้ใช้ขอ: "ให้เก็บแผนนี้ไว้ทำทีหลังจบ worker ทักแชต" · ยังไม่เริ่มออกแบบ/ลงมือ
> ตอนนี้ `dsales_customer_base.rfm_segment` มีค่าแค่ Unscored / Potential / Loyal / Hibernating / Promising / At Risk (ส่วนใหญ่ว่าง) — ระบบเก่าของผู้ใช้แบ่งละเอียดกว่าและมีแคมเปญแนะนำต่อกลุ่ม

## ระบบเก่า (RFM Analysis dashboard)
- ตาราง R (1–5) × F (1–5+) แบ่งกลุ่ม พร้อมจำนวนลูกค้าต่อกลุ่ม · คอลัมน์ Customer ID, เบอร์, ชื่อ, Segment, Frequency, Monetary, R_Score, F_Score, M_Score
- จำนวนตัวอย่างจากภาพ: Lost 5,525 · Cold New Member 2,073 · Hot New Member 2,029 · Warm New Member 1,971 · Promising 987 · Sleepers 494 · Need Attention 355 · Loyal 113 · Champion 39 · Shouldn't Lose 1

## นิยามกลุ่ม (จากผู้ใช้)
| กลุ่ม | เงื่อนไข |
|---|---|
| Champion | ซื้อล่าสุดไม่เกิน 30 วัน และซื้อมากกว่า 5 ครั้ง |
| Loyal Customer | ซื้อล่าสุดไม่เกิน 60–90 วัน และซื้อมากกว่า 4–5 ครั้ง (เริ่มหายเกิน 30 วัน) |
| Promising | ซื้อล่าสุดไม่เกิน 60 วัน และซื้อ 2–3 ครั้ง |
| Need Attention | ซื้อล่าสุดไม่เกิน 60–90 วัน และซื้อ 2–3 ครั้ง (เริ่มหายเกิน 60 วัน) |
| Shouldn't Lose | ซื้อมากกว่า 5 ครั้ง แต่หายเกิน 90 วัน |
| Sleepers | ซื้อ 3–4 ครั้ง แต่หายเกิน 90 วัน |
| Hot New Member | ซื้อครั้งแรก เพิ่งซื้อ 0–30 วัน |
| Warm New Member | ซื้อครั้งแรก เพิ่งซื้อ 31–60 วัน |
| Cold New Member | ซื้อครั้งแรก เพิ่งซื้อ 61–90 วัน |
| Lost | ซื้อ 1–2 ครั้ง แต่หายเกิน 90 วัน |

ช่วงที่ทับกัน (เช่น Loyal "60–90 วัน" กับ "4–5 ครั้ง") ต้องตกลงกติกาให้ชัดตอนออกแบบ (ลำดับการเช็ก / R-F score 1–5 แบบระบบเก่า)

## แคมเปญแนะนำต่อกลุ่ม (Segment guide ของผู้ใช้)
| กลุ่ม | พฤติกรรม | แคมเปญแนะนำ |
|---|---|---|
| Champion | ซื้อบ่อย ซื้อเยอะ | บริการพิเศษ รีวิว ส่งสินค้าใหม่ให้ฟรี ของขวัญวันเกิด ดูแลรักษาไว้ให้ดีที่สุด |
| Loyal Customers | ซื้อประจำ แต่ห่างไปช่วงสั้น ๆ | สะสมแต้มทุกสัปดาห์/เดือน ของขวัญวันเกิด เพื่อเพิ่ม Recency |
| Promising | มาบ่อยพอสมควร ซื้อขนาดกลาง | Up-sell แนะนำสินค้าที่น่าจะถูกใจ อัปเกรดเลเวลสมาชิก เพิ่ม Frequency + Monetary |
| New Customers | ลูกค้าใหม่เพิ่งซื้อครั้งแรก | สร้างความสัมพันธ์ ต้อนรับสมาชิกใหม่ ข่าวสารแบรนด์ สะสมแต้ม |
| Abandoned Checkouts | ออกจากช่องเช็คเอาท์ | แนะนำให้รู้จักแบรนด์มากขึ้น ส่วนลดครั้งแรก |
| Warm Leads | เคยซื้อครั้งเดียวแล้วหาย ยังมีสิทธิตามกลับ | Hard conversation ติดต่อกลับเร็ว ผ่านช่องทางที่ลูกค้าต้องการ |
| Cold Leads | เคยซื้อครั้งเดียวแล้วหาย ตามกลับไม่ทันแล้ว | Soft conversation ไม่กดดัน ติดต่อผ่านสื่อที่ไม่รบกวนมาก |
| Need Attention | มีศักยภาพจะขายได้เพิ่ม | Up-sell / Cross-sell โปรตามเลเวลสมาชิก |
| Shouldn't Lose | ยอดสูงที่หายไปนาน อาจไปซื้อคู่แข่ง | Hard winback โปรแรงในสินค้าที่เคยซื้อ แนะนำสินค้าใหม่ |
| Sleepers | ยอดกลาง ๆ ที่หายไปสักพัก | Soft winback โปรเบา ๆ แนะนำสินค้าที่ถูกใจ |
| Lost | ซื้อน้อย ไม่บ่อย หายไปนาน | หยุดส่งแคมเปญ เอางบไปลงกลุ่มอื่น |

## ไอเดียตอนลงมือ (ยังไม่ได้ตัดสิน)
- คำนวณ R/F/M score และ segment ใน `dsales_refresh_customer_base` (รอบ cron 3 รอบ/วัน) เก็บคอลัมน์ `rfm_r`, `rfm_f`, `rfm_m`, `rfm_segment` ใหม่
- ตัวกรอง "กลุ่มลูกค้า" ในหน้าลูกค้าของฉัน/ถังกลาง (มีแล้วผ่าน `p_filters.rfm`) จะใช้ชื่อกลุ่มใหม่อัตโนมัติ
- ผูก template ข้อความแนะนำต่อกลุ่ม (เช่น winback / welcome) และ Dashboard แบบตาราง R × F
- ตรวจกับข้อมูลจริงว่าจำนวนต่อกลุ่มใกล้กับระบบเก่า (ตัวอย่าง Lost ~5.5k)
